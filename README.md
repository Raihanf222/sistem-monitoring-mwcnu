# Sistem Informasi Monitoring Program Kerja
Dokumentasi analisis dan perancangan sistem — Skripsi S1 Teknik Informatika

---

## Tentang Project

Sistem informasi berbasis web untuk monitoring program kerja organisasi **Majelis Wakil Cabang Nahdlatul Ulama Karang Tengah**. Sistem ini menggantikan proses administrasi manual menjadi digital, mencakup pengajuan, persetujuan, monitoring, dan pelaporan program kerja.

- Periode: Februari 2025 – Juli 2025
- Institusi: Universitas Muhammadiyah Tangerang
- Program Studi: Teknik Informatika

---

## Peran Saya dalam Project

Proyek ini dikerjakan secara kolaboratif. Kontribusi saya meliputi:

- Analisis kebutuhan sistem (requirement gathering)
- Perancangan alur sistem menggunakan UML
- Pembuatan Use Case Diagram, Activity Diagram, dan ERD
- Pengujian fungsional sistem
- Penyusunan dokumentasi dan laporan penelitian

---

## Teknologi yang Digunakan

| Komponen  | Teknologi                  |
|-----------|----------------------------|
| Back-end  | PHP, Laravel Framework     |
| Database  | MySQL                      |
| Front-end | HTML, CSS, Bootstrap       |
| Dokumentasi | UML (draw.io)            |

---

## Fitur Sistem

- Multi-role authentication (Ketua, Sekretaris, Anggota)
- Pengajuan program kerja secara digital
- Alur persetujuan bertingkat
- Monitoring status program kerja
- Laporan otomatis program kerja
